# Hello, I'm onlyfinessegg36 👋

I spend most of my time writing Rust and C close to the metal — building terminal tools, poking at WebAssembly runtimes, and trying to understand what the kernel is actually doing with my syscalls. There's something satisfying about shaving microseconds off a hot path or finally getting a zero-copy parser to click into place. Lately I've been thinking a lot about how the tools we use shape the way we reason about systems, and I keep coming back to Linux and Git as the ones that taught me the most.
